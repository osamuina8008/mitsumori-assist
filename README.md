# 見積算定書アシスト

熱処理見積の算定ツール（社内用）。複数図面を一括管理し、図面ごとに条件（炉種・寸法・温度・深さ・治具・キロ単価・付帯）を設定。
組み付け図を表示し、見積算定書のプレビュー・書き出しまで行う。

## 使う（ブラウザだけで完結）
- 公開URL（GitHub Pages）を開くだけ。スマホ・他PCでも可。
- 入力内容はブラウザに自動保存（端末ごと）。

## Excel算定書にする（Macローカル）
1. ツールで「算定書へ書き出し」→ JSONダウンロード（~/Downloads）
2. `算定書生成.command` をダブルクリック → 0-2テンプレへ流し込んだ xlsx が出来る
   ※ テンプレ `0-2.見積内訳表「3」.xlsx` と同じフォルダに置くこと

## ファイル
- `index.html` … メインツール（複数図面＋算定書）
- `tool_0-1_炉組み.html` … 単品版
- `算定書生成.py` / `算定書生成.command` … xlsx生成（要 python3 + openpyxl + テンプレ）
