================================================================
見積算定書アシスト — 使い方（2026-08-22）
================================================================
場所: 201_正式見積作成手順 / 新 /

【ファイル】
・見積算定書アシスト.html … メインのツール（ブラウザでダブルクリック）
・0-1_炉組みアシスト.html   … 単品版（1図面だけ見たいとき）
・算定書生成.py            … 0-2テンプレへ流し込む生成器
・算定書生成.command       … ↑をダブルクリックで実行
・0-2.見積内訳表「3」.xlsx  … 流し込み先テンプレ（数式はこのまま生きる）

────────────────────────────────────────────────────────────
■ 流れ（複数図面・条件バラバラでOK）
────────────────────────────────────────────────────────────
1. 見積算定書アシスト.html を開く
2. 上段に 得意先・営業・記入日・炉単価（浸炭B/P）を入れる
3. 「図面」列の ＋ で図面を追加。図面ごとに:
   ・炉タブ（バッチ / ピット）を選ぶ
   ・形状・寸法・単重・深さ・温度を入れる
   ・治具ボタン（網 / 4分割 / 2分割 / なし）で組み方を選ぶ
     → バッジに投入可能数、「最多」が推奨
   ・右に組み付け図（平面・立面）が出る
   ・キロ単価がある顧客は「キロ単価」を入れる
     → キロ単価案が算定式下限を下回れば自動で下限に赤字警告
   ・付帯工数（防炭・段取り・サブゼロ等の回数）を入れる
   ・備考は空欄で「深さ・治具」を自動記載（追記も可）
4. 下段「見積算定書プレビュー」で全図面の単価・ロット金額を確認
5. 「算定書へ書き出し」→「JSONダウンロード」
   → ~/Downloads に 算定書_YYYYMMDD_得意先.json が落ちる
6. 算定書生成.command をダブルクリック
   → 同じ場所に 見積算定書.xlsx が出来て自動で開く
     （単価/ヶ・合計単価・時間単価・評価などの数式はテンプレのまま）

────────────────────────────────────────────────────────────
■ 価格の考え方（キロ単価）
────────────────────────────────────────────────────────────
・算定式下限 = 単価/ヶ(原価) × 混載リスク + 付帯/ヶ  （＝テンプレ N6）
・キロ単価案 = キロ単価 × 単重量
・キロ単価案が下限を下回るときは 下限単価 で作成（原価割れ防止）
  最終判断は担当が可（合計単価は手入力で上書きも可能）

────────────────────────────────────────────────────────────
■ 0-2 への対応（テンプレの入力セルだけ埋める）
────────────────────────────────────────────────────────────
  E品番 / F品名 / G処理名 / H ロット数量Max / I 受注量月 /
  J 単重量 / M 混載リスク / N 合計単価 / Q 処理時間 /
  R 処理条件(温度+時間) / 副行J 浸炭B・P / 付帯工数(副行 T..Z) /
  AI 備考(新設列: 深さ・治具)
  ※ K・L・O・P・AB〜AH 等の数式は触らず、Excelで再計算される

・図面PDFは品番ごとに条件が違ってよい（1図面=1行）。
・5件までは「内訳原紙」、6〜13件は「内訳原紙 (13列)」へ自動。
・入力はブラウザに自動保存（次回開くと復元）。
